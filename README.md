# RÈCỌRD Media Agency - Landing Page

Trang Landing Page chính thức của **RÈCỌRD Media Agency** - Media Agency thế hệ mới chuyên chụp ảnh concept, ngoại cảnh, sản xuất video ngắn TikTok/Reels và truyền thông thương hiệu cho Gen Z & Local Brand.

## ✨ Tính năng nổi bật

- **Thiết kế hiện đại & Tinh tế**: Giao diện Light Studio cao cấp với hiệu ứng chuyển động mượt mà, tối ưu trên mọi kích thước màn hình (Responsive Mobile/Tablet/Desktop).
- **Bộ tính giá & Đặt lịch linh hoạt**: Khách hàng có thể chọn dịch vụ, gói chụp/quay, phụ phí và xem báo giá trực tiếp theo thời gian thực.
- **Tích hợp Google Sheets qua Google Apps Script**: Tự động lưu thông tin khách đặt lịch vào Google Trang tính thuận tiện cho việc quản lý đơn.
- **Bộ lọc Portfolio & Thư viện dự án**: Phân loại theo Concept, Lookbook, Video ngắn, Sự kiện,...
- **Tối ưu SEO**: Đầy đủ thẻ Open Graph, Meta tags, tối ưu tốc độ tải trang.

## 🛠️ Công nghệ sử dụng

- **Frontend**: HTML5, Vanilla JavaScript (ES6+), CSS3
- **CSS Framework**: Tailwind CSS (CDN)
- **Icons**: Lucide Icons
- **Backend / Form Endpoint**: Google Apps Script (`google_apps_script.js`) & Google Sheets

## 🚀 Cấu trúc thư mục

```text
├── assets/
│   └── images/            # Hình ảnh dự án, logo, banner
├── css/
│   └── style.css          # Tùy chỉnh CSS giao diện
├── js/
│   └── main.js            # Xử lý logic đặt lịch, tính giá, animations
├── google_apps_script.js  # Mã nguồn Apps Script lưu đơn vào Google Sheet
├── index.html             # Giao diện chính của Landing Page
└── README.md
```

Chi tiết từng bước cấu hình xem tại phần chú thích ở đầu tệp [google_apps_script.js](google_apps_script.js).
